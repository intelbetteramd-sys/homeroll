# Security Policy / Политика безопасности

## Reporting a vulnerability

Please **do not** open a public issue for security problems. Report them privately via
**Security → Report a vulnerability** on this repository (GitHub private vulnerability reporting).

We aim to acknowledge reports within 7 days and will keep you updated on the fix.

## Как сообщить об уязвимости

Пожалуйста, **не создавайте** публичный issue. Сообщите приватно через вкладку
**Security → Report a vulnerability** в этом репозитории.

Постараемся ответить в течение 7 дней и будем держать вас в курсе исправления.

## Что особенно важно

Homeroll работает с личными фотографиями, поэтому нас особенно интересуют:

- возможность получить или удалить фото без ведома пользователя;
- обход сопряжения устройств или подмена ПК в локальной сети;
- утечка токенов облачных сервисов;
- ошибки, из-за которых уборка может удалить последнюю копию фотографии.

## Supported versions

The project has no releases yet. After v1.0, security fixes go to the latest release.
