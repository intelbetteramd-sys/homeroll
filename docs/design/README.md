# Дизайн

> **Статус: не начато.** Дизайн приложения, сайта и дизайн-система будут обсуждаться отдельно.
> Здесь только рамка: что нужно решить и что уже известно из требований.

## Что предстоит решить

### Бренд
- [ ] Характер продукта и тон общения (как приложение разговаривает с пользователем).
- [ ] Логотип и иконка приложения. Сейчас в [`assets/logo.svg`](../assets/logo.svg) лежит **временная заглушка**.
- [ ] Цветовая палитра, шрифт (с хорошей кириллицей), иконки.

### Дизайн-система
- [ ] Токены: цвета (светлая и тёмная темы), типографика, отступы, скругления, тени, анимации.
- [ ] Набор компонентов и их состояния.
- [ ] Инструменты: где рисуем макеты и как токены попадают в код (модуль `:shared:designsystem`).

### Платформы
- [ ] Насколько интерфейс одинаковый на Android, iOS, macOS и Windows, а где следует привычкам платформы
      (навигация, жесты, контекстные меню, горячие клавиши).
- [ ] Адаптивность: телефон, планшет, окно на ПК.

### Экраны и сценарии
- [ ] Информационная архитектура: навигация на телефоне и на ПК.
- [ ] Ключевые сценарии: первый запуск, подключение облака, сопряжение с ПК по QR, отправка на ПК,
      уборка дублей, импорт Google Takeout.
- [ ] Пустые состояния, ошибки, ограничения сервисов («Google Фото даёт доступ только к выбранным фото»).

### Сайт
- [ ] Лендинг: структура, скачивание, политика конфиденциальности, FAQ.
- [ ] Общая с приложением визуальная система.

## Что уже зафиксировано требованиями

Эти вещи следуют из продукта и сторов — дизайн должен их учесть:

- Функции v1.0 и матрица платформ — [requirements.md](../product/requirements.md).
- Интерфейс на **Compose Multiplatform** для всех платформ — [ADR 0001](../architecture/adr/0001-kotlin-multiplatform-compose.md).
- Два языка с первого дня: **RU и EN**, включая русские множественные формы.
- **Доступность:** VoiceOver и TalkBack, увеличенный шрифт до 200%, контраст WCAG AA, цели касания ≥ 44 pt.
- **Светлая и тёмная** темы.
- Удаление — самое опасное действие: сводка, подтверждение, понятный отчёт ([безопасность](../architecture/security-privacy.md)).
- Логотипы облачных сервисов — только по их брендбукам. Чужие бренды нельзя использовать в иконке и
  названии приложения (правило App Store с июня 2026).
