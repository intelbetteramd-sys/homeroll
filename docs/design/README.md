## Макеты

Все макеты на одном холсте: **[Pixroost — макеты](https://claude.ai/artifact/TA6Yi6zVfd8kAGQNyzfJhp)**.
Холст приватный: откроется у тех, с кем владелец им поделится.

Экраны Android, Windows, iPhone и macOS связаны ссылками: по ним можно пройти сценарий кликами.
Начинать удобно с «Первого запуска» на Android.

| Ряд на холсте | Экраны |
|---|---|
| Основа | токены, компоненты |
| Android: телефон и планшет, v1.0 | первый запуск, лента, лента в первые дни (ограниченный доступ, ошибка облака), выбор и отправка на ПК, «Где лежит», хранилища, уборка, группа дублей, подтверждение, итог уборки, устройства, добавление ПК по QR, планшет: лента с панелью «Где лежит» |
| Windows, v1.0 | лента с панелью «Где лежит» и подсказкой про Яндекс Диск, уборка с таблицей копий и горячими клавишами, добавление телефона (QR и код), трей |
| iPhone, после v1.0 | лента в тёмной теме, «Где лежит», уборка с предупреждением про Фото iCloud, устройства с честным статусом фоновой отправки |
| macOS, после v1.0 | лента с инспектором, строка меню |

Главный сценарий «переполнено → освободить»: Хранилища → «Разобрать» → Уборка → «Удалить 1 240 копий» →
подтверждение → «Освобождено 6,3 ГБ».

## Визуальное направление: «Сумерки и свет в окне»

Вечерний дом, в окне горит свет — значит, дома всё в порядке. Интерфейс спокойный, сумеречно-синий.
Тёплый жёлтый «свет в окне» появляется только там, где фото уже лежит на ПК пользователя и проверено.
Это прямое следствие вывода «Дом — это безопасность» из [исследования](research.md#выводы).

Чего избегаем: градиентов, одинаковых карточек, КАПСА в подписях, «чистильщицкого» красного и срочности.
Красный — только для удаления.

### Цвета

| Токен | Название | HEX | Роль |
|---|---|---|---|
| `fog` | Туман | `#F3F5F9` | фон экранов |
| `paper` | Бумага | `#FFFFFF` | карточки, листы, панели |
| `ink` | Чернила | `#172036` | основной текст и иконки |
| `slate` | Сланец | `#5B657A` | вторичный текст, контуры полей, выключенный переключатель |
| `line` | Линия | `#DDE2EB` | разделители (декоративные) |
| `dusk` | Сумерки | `#22305C` | главное действие, выбор, прогресс, фокус |
| `dusk-tint` | Сумерки светлые | `#E4E8F3` | тональные кнопки, выбранный пункт навигации |
| `lamp` | Лампа | `#F2A93B` | только «сохранено дома» |
| `lamp-tint` | Лампа светлая | `#FDF1DC` | статус «сохранено», правило безопасности |
| `danger` | Опасность | `#B42318` | только удаление |
| `danger-tint` | Опасность светлая | `#FBE9E7` | фон метки «Почти заполнен» |

Тёмная тема: `night` `#0F1528` (фон), `night-surface` `#182038`, `night-line` `#2A3350`,
`night-text` `#E8ECF4`, `night-slate` `#A3ADC2`, `dusk-light` `#9DB0F0` (акцент и фокус).

Все пары «текст — фон» проходят WCAG AA; таблица контрастов — в [review-findings.md](review-findings.md#контраст).
Жёлтый на белом даёт только 2,0:1, поэтому знак лампы всегда с тёмным контуром.

### Шрифты

- **Unbounded 600** — крупные заголовки и итоговые цифры («Освобождено 6,3 ГБ»).
- **Onest 400 и 600** — весь интерфейс.

Оба с хорошей кириллицей и под лицензией SIL OFL 1.1: файлы шрифтов кладём в приложение
(никаких запросов к Google Fonts), текст лицензии — в `NOTICE`.

| Шкала | Размеры | Где |
|---|---|---|
| Телефон и планшет | 28, 18, 15, 13 | крупный заголовок, заголовок блока, текст и кнопки, подписи |
| ПК | 28, 20, 14, 12 | как шкала Fluent: заголовок, подзаголовок, текст, подписи |

Системные компоненты (панель вкладок iOS) используют системный размер подписей.

### Сетка и формы

- Отступы кратны 4 и 8: 4, 8, 12, 16, 24, 32, 48.
- Скругления: 4 (Windows), 8 (превью), 16 (плашки), 20 (карточки), 28 (листы), полностью (кнопки на телефоне).
- Цели касания на телефоне ≥ 44 px, на ПК ≥ 32 px.

### Знак «свет в окне»

Окно с переплётом, залитое жёлтым, с тёмным контуром. Отмечает всё, что уже лежит на ПК и проверено:
метку места на превью, статус «Всё сохранено», строку «ПК „Дом“» в списке копий, итог уборки.
Для других смыслов не используется. Может стать основой логотипа вместо временной
[заглушки](../assets/logo.svg).

## Платформы

| Платформа | Как выглядит | Правила |
|---|---|---|
| Android | Material 3 Expressive | компактная нижняя навигация; действия с выбранными — плавающая панель; детали — нижний лист |
| Планшет Android | rail + список и детали | панель «Где лежит» справа вместо листа |
| iPhone | iOS 26, Liquid Glass | стекло только на слое навигации (вкладки, кнопки поверх фото); стекло не кладём на стекло; цветом выделяем только одно главное действие |
| Windows | Fluent, WinUI 3 | NavigationView слева, фон Mica, InfoBar для подсказок, диалоги ContentDialog, горячие клавиши |
| macOS | Tahoe | стеклянный сайдбар, инспектор справа, строка меню вместо трея |

Цвета, знаки мест, статусы и тексты одинаковы везде; меняются навигация, формы кнопок и жесты.

## Что уже зафиксировано требованиями

Эти вещи следуют из продукта и сторов — дизайн должен их учесть:

- Функции v1.0 и матрица платформ — [requirements.md](../product/requirements.md).
- Интерфейс на **Compose Multiplatform** для всех платформ — [ADR 0001](../architecture/adr/0001-kotlin-multiplatform-compose.md).
- Два языка с первого дня: **RU и EN**, включая русские множественные формы.
- **Доступность:** VoiceOver и TalkBack, увеличенный шрифт до 200%, контраст WCAG AA, цели касания ≥ 44 pt.
- **Светлая и тёмная** темы.
- Удаление — самое опасное действие: сводка, подтверждение, понятный отчёт ([безопасность](../architecture/security-privacy.md)).
- Логотипы облачных сервисов — только по их брендбукам. Чужие бренды нельзя использовать в иконке и
  названии приложения (правило App Store с июня 2026).
