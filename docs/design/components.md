# Компоненты

Что нужно модулю `:shared:designsystem`, чтобы собрать [макеты v1](README.md#макеты).
Имена — по [конвенциям](../process/conventions.md): существительное с префиксом `Px`.
Своей дизайн-системы в коде пока нет, поэтому здесь все компоненты новые; в колонке «Основа» —
на что опираться в Compose.

## Токены

| Объект в коде | Что внутри | Источник |
|---|---|---|
| `PxColors` | светлая и тёмная палитры | [README](README.md#цвета) |
| `PxTypography` | шкала телефона 28/18/15/13 и ПК 28/20/14/12, Unbounded и Onest | [README](README.md#шрифты) |
| `PxSpacing` | 4, 8, 12, 16, 24, 32, 48 | [README](README.md#сетка-и-формы) |
| `PxShapes` | 4, 8, 16, 20, 28, полное скругление | [README](README.md#сетка-и-формы) |
| `PxTheme` | собирает всё выше; на Android — поверх `MaterialTheme` | — |

## Общие компоненты

| Компонент | Что делает | Где в макетах | Основа |
|---|---|---|---|
| `PxLamp` | знак «свет в окне»: копия на ПК проверена | везде, где есть ПК | своя отрисовка (Canvas) |
| `PxSourceMark` | круглая метка места: буква облака, телефон, ноутбук, лампа для ПК; скрыта от скринридера | строки копий, хранилища, устройства | свой |
| `PxMediaThumbnail` | превью фото: метки мест, длительность видео, состояние выбора, имя для скринридера со списком мест | лента, уборка, трей | Coil 3 + свой слой поверх |
| `PxMediaGrid` | сетка превью с заголовками дат и быстрым скроллером | лента на всех платформах | `LazyVerticalGrid` |
| `PxButton` | варианты: главная, тональная, контурная, опасная, текстовая, «лампа» | все экраны | `Button` Material 3 |
| `PxIconButton` | кнопка-иконка с обязательной подписью для скринридера | верхние панели | `IconButton` |
| `PxFilterChips` | фильтр ленты: «Все», «Нет на ПК», «Только в облаках», «Видео»; зона касания 44 | лента | `FilterChip` |
| `PxArchiveStatus` | статус архива: «Всё сохранено», «Ждёт ПК», «Пауза: нет Wi-Fi»; ведёт в «Устройства» | лента, компоненты | свой |
| `PxBadge` | метки «Проверено», «Автоархив», «Отмечено», «Копия», «Хуже», «Почти заполнен» | строки и карточки | свой |
| `PxCopyRow` | строка «Где лежит»: место, качество, размер, метка или переключатель | «Где лежит», группа дублей | `ListItem` |
| `PxDeleteToggle` | чекбокс «Удалить» с контекстом для скринридера («копию из Яндекс Диска») | группа дублей, уборка на ПК | `Checkbox` + своя подпись |
| `PxUsageBar` | заполненность хранилища: занято и сколько можно освободить | хранилища | свой |
| `PxProgress` | прогресс передачи | устройства, трей | `LinearProgressIndicator` |
| `PxReclaimCard` | «Можно освободить 6,3 ГБ» с переходом в уборку | хранилища | свой |
| `PxCleanupGroupCard` | вид дублей: превью, сколько файлов и места, кто решает | уборка | `Card` |
| `PxSafetyNote` | правило безопасности со знаком лампы | уборка, подтверждение | свой |
| `PxInfoNote` | нейтральная подсказка с иконкой | ограничения сервисов, iCloud, фон на iPhone | свой |
| `PxConfirmSheet` | подтверждение удаления: сводка по местам, правило безопасности, опасная кнопка | подтверждение | `ModalBottomSheet`, на ПК — диалог |
| `PxResultScreen` | итог с главной цифрой, разбивкой по местам и неудачами | «Освобождено 6,3 ГБ» | свой |
| `PxDeviceCard` | устройство: статус сети, автоархив, прогресс, действия | устройства | `Card` |
| `PxOfferCard` | спокойное предложение: подключить облако, добавить ПК | лента в первые дни | `Card` |
| `PxLimitedAccessBanner` | «Видны 120 фото, которые вы выбрали» + «Открыть доступ ко всем» | лента в первые дни | свой |
| `PxSnackbar` | ошибка с действием («Повторить») | лента в первые дни | `Snackbar` |
| `PxQrScanner` | камера с рамкой, запасной ввод кода | добавление ПК | CameraX / AVFoundation через `expect`/`actual` |
| `PxPairingCode` | QR и шестизначный код со сроком действия | добавление телефона на ПК | генератор QR + свой |

## Компоненты платформ

| Компонент | Платформа | Что делает | Основа |
|---|---|---|---|
| `PxNavigationBar` | Android | нижняя навигация, 4 раздела | `NavigationBar` |
| `PxNavigationRail` | планшет Android | rail с кнопкой «Отправить на ПК» | `NavigationRail` |
| `PxFloatingToolbar` | Android | действия с выбранными фото | плавающая панель Material 3 Expressive, если есть в версии Compose Multiplatform; иначе своя |
| `PxWhereSheet` / `PxWherePane` | телефон / планшет и ПК | «Где лежит»: лист снизу или панель справа | `ModalBottomSheet` / свой |
| `PxGlassTabBar` | iPhone | плавающая стеклянная панель вкладок и кнопка поиска | системная панель через interop или имитация — решить в спайке |
| `PxGlassButton` | iPhone, macOS | кнопка на стекле поверх фото или в панели инструментов | то же |
| `PxLargeTitle` | iPhone | крупный заголовок и кнопки на стекле | свой |
| `PxSwitch` | iPhone, настройки | переключатель; выключенный — цвет «Сланец» | `Switch` |
| `PxNavigationPane` | Windows | левая навигация с индикатором, статус приёма внизу | свой по образцу NavigationView |
| `PxTitleBar` | Windows | заголовок окна с поиском | `WindowDraggableArea` в Compose Desktop |
| `PxInfoBar` | Windows | подсказка с действием и закрытием | свой по образцу InfoBar |
| `PxCommandBar` | Windows | панель команд над сеткой | свой |
| `PxSelectorBar` | Windows | вкладки видов дублей | `TabRow` |
| `PxDataTable` | Windows, macOS | таблица копий в уборке | свой |
| `PxKeyHint` | Windows, macOS | подсказка горячей клавиши | свой |
| `PxSidebar` | macOS | стеклянный сайдбар: разделы и места | свой |
| `PxInspector` | macOS | правая панель «Где лежит» | свой |
| `PxTrayPanel` | Windows, macOS | трей и строка меню: статус приёма, передача, последние фото, устройства | `Tray` и окно Compose Desktop |

## Чего ещё нет в макетах

Эти компоненты понадобятся для экранов из [рекомендаций](review-findings.md#рекомендации):

| Компонент | Зачем |
|---|---|
| `PxImportProgress` | импорт Google Takeout: этапы, прогресс, найденные дубли |
| `PxCleanupLogItem` | журнал уборки и возврат из корзины |
| `PxSourcePicker` | выбор облака при подключении |
| `PxSettingsItem` | настройки: автоархив, раскладка, блокировка |
| `PxNotification` | уведомления Android: передача и «хранилище заполнено» |
| `PxEmptyState` | пустые разделы («Устройств пока нет») |
