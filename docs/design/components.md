# Компоненты

Что нужно модулю `:shared:designsystem`, чтобы собрать [макеты v1](README.md#макеты).
Имена — по [конвенциям](../process/conventions.md#compose): по назначению, без префикса проекта. Где имя совпало бы
с Material 3 (`Button`, `Badge`, `Switch`), роль уточнена: `PrimaryButton`, `StatusBadge`, `SettingSwitch`.
Элементы Windows в стиле Fluent — с приставкой `Fluent`, macOS и iOS — `Mac` и `Ios`: это стиль, а не имя проекта.
Своей дизайн-системы в коде пока нет, поэтому здесь все компоненты новые; в колонке «Основа» —
на что опираться в Compose.

## iOS и macOS (третья итерация)

Кто что рисует — по [ADR 0009](../architecture/adr/0009-liquid-glass-native-navigation.md). «Система» — нативный компонент SwiftUI, его в `:shared:designsystem` нет.
Все образцы — на доске `DS-Apple` холста.

| Элемент | Платформа | Кто рисует | Основа |
|---|---|---|---|
| Панель вкладок и кнопка поиска | iPhone | система | `TabView`, роль поиска у вкладки |
| Сайдбар разделов | iPad | система | `TabView` с `.sidebarAdaptable` |
| Заголовок, «назад», кнопки на стекле | iPhone, iPad | система | `NavigationStack`, `.toolbar`; символ и подпись — в разных группах |
| Главное действие | iPhone, iPad | система | `.buttonStyle(.glassProminent)`, одно на экран |
| Панель действий с выбранными | iPhone | система | нижний `.toolbar` |
| Листы: «Где лежит», подтверждение, подключение | iPhone | система | `.sheet` с уровнями высоты, содержимое — Compose |
| `EdgeFade` | iPhone, iPad | Compose | мягкое затухание контента у стеклянных панелей: системный эффект края прокрутки со скроллом Compose не работает |
| `GroupedList` | iPhone, iPad | Compose | группы строк со скруглением 26 и подписью под группой, как в настройках iOS |
| `IosSwitch`, `CheckCircle` | iPhone, iPad | Compose | переключатель и круглая отметка выбора в стиле iOS |
| `MacWindow` | macOS | Compose Desktop | окно с прозрачным заголовком, «светофором» и панелью инструментов |
| `Sidebar` | macOS | Compose Desktop + стекло из SwiftUI-библиотеки | сайдбар разделов и мест; под ним `NSGlassEffectView`, запасной вариант — заливка |
| `MacButton`, `MacSwitch`, `MacCheckbox`, `MacRadio` | macOS | Compose Desktop | элементы управления AppKit по размерам Tahoe |
| `MacSheet` | macOS | Compose Desktop | лист поверх окна: добавление телефона, подтверждение |
| Окно настроек | macOS | система | SwiftUI `Form` с вкладками-иконками в отдельном окне |
| Панель в строке меню | macOS | система | `NSStatusItem` и всплывающая панель на SwiftUI; на Windows — `TrayPanel` |
