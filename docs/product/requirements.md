# Требования к v1.0

Первая публичная версия. Всё, что ниже, должно работать к релизу в сторах.
Что **не** входит в v1.0 — в конце документа.

Связанные документы: [видение](vision.md) · [источники](sources.md) · [дизайн](../design/README.md) ·
[роадмап](../roadmap.md).

| Платформа | Минимальная версия | Приложение | Когда |
|---|---|---|---|
| Android | 8.0 (API 26) | телефон и планшет | **v1.0** |
| Windows | 10 (64-bit) | desktop | **v1.0** |
| Linux | — | desktop, бонус из той же сборки, без официальной поддержки | v1.0 |

| macOS | 12 Monterey, Apple Silicon и Intel | desktop | этап «iOS и macOS» |

iOS и macOS — когда появятся Mac и Apple Developer Program. Требования ниже написаны для всех платформ,
пометки «iOS» относятся к этому этапу.

## Эпики и пользовательские истории

### E1. Онбординг и разрешения

- **E1.1** Как новый пользователь, я за 3 экрана понимаю, что делает приложение, и даю доступ к галерее.
- **E1.2** Если я даю **ограниченный доступ** (iOS Limited Library, Android 14+ «выбранные фото»), приложение
  работает с тем, что доступно, и объясняет, чего я лишаюсь.
- **E1.3** Приложение **полезно без ПК и без облаков**: лента галереи и дубли внутри неё работают сразу.
  *(Важно и для проверки в App Store: ревьюер должен увидеть ценность без второго устройства.)*
- **E1.4** Подключение облаков и ПК предлагается, но его можно пропустить.

### E2. Источники

Подробный список и ограничения — в [sources.md](sources.md).

- **E2.1** Я подключаю облако в 2 касания: вход через браузер (OAuth), без ввода пароля в приложении.
- **E2.2** Для каждого источника я вижу статус: синхронизируется / готово / нужен повторный вход / ошибка.
- **E2.3** Я вижу заполненность каждого облака (если сервис её отдаёт).
- **E2.4** Синхронизация **инкрементальная**: повторный запуск подтягивает только изменения.
- **E2.5** По умолчанию доступ **только на чтение**. Удаление — отдельное явное действие (E4).
- **E2.6** Я могу отключить источник — все его данные удаляются из локальной базы.

### E3. Единая лента

- **E3.1** Лента по дням и месяцам, плавная прокрутка на **50 000+** элементов, быстрый скроллер по датам.
- **E3.2** На превью значки источников: где лежат копии этой фотографии.
- **E3.3** Фильтры: по источникам, по типу (фото / видео / Live Photo / скриншоты), «нет в архиве на ПК».
- **E3.4** Карточка **«Где лежит»**: все копии, источник, размер, качество (оригинал / сжатая копия).
- **E3.5** Просмотр фото, видео и Live Photo: зум, свайпы, информация (дата, размеры, камера).
- **E3.6** Множественный выбор с действиями: «Отправить на ПК», «Удалить из…», «Поделиться».
- **E3.7** Pinch-to-zoom для смены плотности сетки на телефоне; на ПК — слайдер и `Ctrl/⌘ +/-`.

### E4. Дубли и уборка

- **E4.1** **Точные дубли** — одинаковые файлы в разных источниках — найдены автоматически.
- **E4.2** **Та же фотография в другом качестве** (оригинал в iCloud и сжатая копия в Google Фото)
  показана отдельной группой: решение за пользователем.
- **E4.3** **Похожие кадры** (серии) — отдельная вкладка, ничего не выбрано по умолчанию.
- **E4.4** Экран «Хранилища»: по каждому источнику «занято / можно освободить».
- **E4.5** **План уборки:** предпросмотр → сводка («удалим 1 240 файлов, 6,3 ГБ из Яндекс Диска») →
  подтверждение → удаление **в корзину** источника → отчёт.
- **E4.6** **Правило безопасности:** нельзя удалить копию, если у фотографии не остаётся хотя бы одной
  **проверенной** копии (совпадение SHA-256) в месте, которое пользователь отметил надёжным
  (по умолчанию — архив на ПК).
- **E4.7** Журнал действий: что, откуда и когда удалено, с подсказкой, где искать корзину.

### E5. Устройства

- **E5.1** На ПК я нажимаю «Добавить телефон» и вижу QR-код; на телефоне сканирую его — готово.
  Без логинов, паролей и почты.
- **E5.2** ПК спрашивает подтверждение: «Подключить iPhone Ани?».
- **E5.3** На телефоне список моих ПК: имя, платформа, в сети / не в сети, когда был последний раз.
- **E5.4** Можно связать **несколько ПК** и выбрать ПК по умолчанию для автоархива.
- **E5.5** Любое устройство можно «забыть» с обеих сторон. Отозванный ключ перестаёт работать сразу.
- **E5.6** Уже связанный телефон может **пригласить** второй телефон по QR, не подходя к ПК
  (если у него есть право «Управление устройствами»).
- **E5.7** **Права устройства** задаются на ПК: отправка в архив, просмотр архива, скачивание,
  управление устройствами. Пример: телефону бабушки — только «отправлять фото на ПК».
- **E5.8** **Блокировка приложения** (по желанию): Face ID / Touch ID / отпечаток / PIN при открытии
  и перед просмотром архива на ПК. Автоархив работает и без разблокировки приложения.
- **E5.9** ПК ведёт **журнал подключений** и показывает уведомления: «добавлено новое устройство»,
  «устройство отозвано», «подключение из новой сети».
- **E5.10** Приложение советует базовую гигиену: включить код блокировки на телефоне и шифрование диска
  на ПК (BitLocker / FileVault), предупреждает о root / джейлбрейке.

Модель ключей и угроз — в [безопасности и приватности](../architecture/security-privacy.md).

### E6. Отправка на ПК

- **E6.1** Выбрал фото → «Отправить на ПК» → выбрал ПК → очередь с прогрессом.
- **E6.2** Обрыв связи не страшен: передача **докачивается** с места остановки.
- **E6.3** Если ПК не в сети — задания ждут и уходят, когда ПК появится.
- **E6.4** ПК сохраняет **оригиналы без пережатия**, с EXIF, датой съёмки как датой файла,
  Live Photo — парой файлов с одинаковым именем.
- **E6.5** Раскладка по правилу: по умолчанию `Архив/{год}/{год}-{месяц}/{имя файла}`. Правило настраивается.
- **E6.6** Повторно отправленные файлы не дублируются: ПК узнаёт их по хэшу и пропускает.
- **E6.7** После проверки хэша фото помечается «в архиве», и приложение предлагает
  **освободить место на телефоне** — с предупреждением, если на iPhone включены iCloud Фото
  (удаление на телефоне удалит и из iCloud).

### E7. Автоархив

- **E7.1** Новые фото сами уходят на выбранный ПК, **когда он доступен в сети**.
- **E7.2** Условия настраиваются: только на зарядке, только по Wi-Fi без ограничения трафика.
- **E7.3** Android — надёжно в фоне (WorkManager).
  iOS — в фоне, когда система разрешит, и гарантированно при открытии приложения.
  Ограничение iOS **честно объясняется** в интерфейсе.
- **E7.4** Статус автоархива виден на главном экране: «Всё сохранено» / «Ждёт ПК: 34 фото».

### E8. Desktop-приложение

- **E8.1** Живёт в трее (Windows) / строке меню (macOS), запускается вместе с системой.
- **E8.2** Первый запуск: выбор папки архива и правила раскладки.
- **E8.3** Принимает файлы от сопряжённых телефонов, показывает историю приёма.
- **E8.4** Источники-папки: любые папки и внешние диски, в том числе **папки синхронизации клиентов облаков**
  (iCloud для Windows, Google Drive, Яндекс Диск, Облако Mail.ru, OneDrive, Dropbox).
- **E8.5** Импорт **Google Takeout** (zip или распакованная папка) с восстановлением дат из JSON-файлов.
- **E8.6** Та же единая лента и уборка — на большом экране, с горячими клавишами и drag & drop.
- **E8.7** Проверка обновлений через GitHub Releases.

### E9. Настройки и приватность

- **E9.1** Язык: русский / английский. Тема: системная / светлая / тёмная.
- **E9.2** Экспорт диагностического журнала вручную (для баг-репорта). Никакой автоматической аналитики.
- **E9.3** «Удалить все данные приложения» — стирает локальную базу, токены и ключи.
- **E9.4** Экран «О приложении»: версия, лицензии open source, политика конфиденциальности,
  пользовательское соглашение.

### E10. Качество

- **E10.1** Доступность: VoiceOver / TalkBack, увеличенный шрифт до 200%, контраст WCAG AA, цели касания ≥ 44 pt.
- **E10.2** Производительность: холодный старт < 2 с на среднем телефоне, прокрутка ленты без рывков.
- **E10.3** Индексация 20 000 фото галереи — < 3 мин на среднем телефоне, в фоне, без блокировки UI.
- **E10.4** Crash-free ≥ 99,5% на бете.
- **E10.5** Локализация RU и EN с первого дня, включая русские множественные формы.

## Не входит в v1.0

| Что | Когда |
|---|---|
| iOS, iPadOS и macOS | этап «iOS и macOS» — когда появятся Mac и Apple Developer Program |
| Передача через интернет (не в одной сети) | v1.1 — через relay-сервер без хранения данных |
| Синхронизация подключённых облаков и настроек между устройствами | v1.2 |
| Библиотека «Фото» на macOS напрямую (сейчас — через папку/экспорт) | v1.x |
| Сжатие видео, большие видео, скриншоты, размытые кадры | v1.x |
| Веб-приложение | v2 (Compose Multiplatform Web) |
| Семейный доступ, общие альбомы | v2 |
| Распознавание лиц, поиск по содержимому | v2+ (только на устройстве) |
| Платные функции | не раньше, чем продукт полюбят; только разовая покупка |
| Облако Mail.ru на бесплатном тарифе | нет официального API; только через папку синхронизации на ПК |
