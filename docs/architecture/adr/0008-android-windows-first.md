# 0008. Сначала Android и Windows, iOS и macOS — позже

- Статус: Принято
- Дата: 2026-09-24

## Контекст

Бюджета на старте нет. Для iOS и macOS нужны Mac (Kotlin/Native собирает Apple-таргеты только на macOS)
и Apple Developer Program ($99 в год) для публикации и подписи. Для Android, Windows и Linux достаточно
ПК на Windows, а публикация возможна бесплатно: RuStore, Microsoft Store (регистрация физлиц бесплатна
с сентября 2025), GitHub Releases.

## Решение

- **v1.0 выходит на Android и Windows** (плюс Linux из той же desktop-сборки).
- **iOS и macOS** — отдельный этап, который начинается, когда появятся деньги на Mac и аккаунт Apple.
  Он не привязан к номеру версии и может выйти в любой `1.x`.
- Архитектура остаётся мультиплатформенной: iOS-модули и `iosMain` заводятся сразу, общий код не зависит
  от Android-специфики, решения для iOS (Secure Enclave, PhotoKit, фон) остаются в документации.
- Разработка ведётся на Windows в Android Studio. Сборку iOS можно проверять на macOS-раннерах GitHub Actions
  (бесплатно для публичного репозитория), но отлаживать iOS без Mac не планируем.

## Альтернативы

| Вариант | Почему нет |
|---|---|
| Ждать денег и выпускать сразу на всех платформах | откладывает релиз на неопределённый срок |
| Только Android | ПК-архив — половина ценности продукта, без desktop-версии она теряется |
| Mac в аренду в облаке | платно и неудобно для ежедневной разработки |

## Последствия

- ➕ Можно начинать сразу и выпустить v1.0 без затрат.
- ➕ Android-аудитория в России больше, а RuStore — главный стор для неё.
- ➖ Пользователи iPhone ждут. Лендинг и README честно пишут, что iOS будет позже.
- ➖ Риск, что общий код незаметно «заточится» под Android. Защита — CI собирает iOS-фреймворк на macOS-раннере.

## Дополнение от 2026-09-25

Для разработки теперь есть Mac и iPhone, не хватает только Apple Developer Program ($99 в год). Решение не меняется:
v1.0 выходит на Android и Windows. Меняется то, что можно делать бесплатно уже сейчас:

- собирать iOS-приложение на Mac и ставить его на свой iPhone с бесплатным Apple ID (Personal Team).
  Такая установка работает 7 дней, потом приложение переустанавливают из Xcode;
- запускать desktop-версию на Mac: для запуска на своём компьютере подпись не нужна;
- делать спайки для Apple (S-01, S-08, S-09) параллельно с Фазой 1.

$99 нужны для TestFlight, App Store и нотаризации `.dmg`. Шаги — в треке «Apple»
[плана разработки](../../development-plan.md#трек-apple--параллельно-и-бесплатно).
