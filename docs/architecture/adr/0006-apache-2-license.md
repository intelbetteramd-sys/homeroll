# 0006. Лицензия Apache-2.0

- Статус: Принято
- Дата: 2026-09-24

## Контекст

Репозиторий публичный. Открытый код — часть обещания приватности: любой может проверить, что фото
никуда не уходят. Приложение будет распространяться через App Store, Google Play, RuStore и Microsoft Store.

## Решение

Код распространяется под **Apache License 2.0**. Файлы `LICENSE` и `NOTICE` — в корне репозитория.

## Альтернативы

| Вариант | Почему нет |
|---|---|
| GPL-3.0 | условия App Store конфликтуют с GPL для кода сторонних контрибьюторов → понадобился бы CLA |
| MIT | нет явной патентной оговорки; Apache-2.0 лучше защищает контрибьюторов и пользователей |
| Без лицензии (только посмотреть код) | нельзя принимать вклад сообщества, нельзя в F-Droid |

## Последствия

- ➕ Совместима со всеми сторами, понятна контрибьюторам, есть патентная защита.
- ➕ Возможна публикация в F-Droid (если не зависеть от проприетарных SDK — например, для QR берём ZXing, а не ML Kit).
- ➖ Любой может форкнуть и выпустить клон. Защита — бренд, качество и скорость развития.
  Название и логотип Pixroost лицензией не передаются (Apache-2.0, раздел 6).
