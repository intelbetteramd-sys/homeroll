# 0004. SQLDelight для локальной базы

- Статус: Заменено [0010](0010-room3.md)
- Дата: 2026-09-24

## Контекст

Нужна локальная реляционная БД на Android, iOS и JVM desktop: десятки тысяч записей, группировки по
хэшам, поиск похожих через индексы, пагинация, реактивные запросы (`Flow`), миграции.

## Решение

**SQLDelight 2.x**: схема и запросы пишутся на SQL (`.sq`), библиотека проверяет их при компиляции и
генерирует типобезопасный Kotlin API. Реактивность — через `asFlow()`, пагинация — через расширение для Paging 3.

## Альтернативы

| Вариант | Почему нет (пока) |
|---|---|
| Room 3.0 | в марте 2026 вышла альфа с полноценной поддержкой KMP. Хороший вариант для Android-разработчиков, но на старте проекта ещё не стабилен. **Пересмотреть**, когда выйдет стабильная версия |
| Room 2.7+ (KMP) | переходит в режим поддержки после выхода Room 3 |
| Realm Kotlin | не реляционная модель, развитие проекта замедлилось |
| Хранить всё в файлах / key-value | нет индексов и запросов для дублей |

## Последствия

- ➕ Явный SQL — удобно для сложных запросов (дубли, группировки, LSH-полосы pHash).
- ➕ Зрелая поддержка KMP, проверка миграций в CI.
- ➖ SQL нужно писать руками (для этого проекта скорее плюс).
