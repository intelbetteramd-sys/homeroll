# Архитектурные решения (ADR)

ADR (Architecture Decision Record) — короткая запись о решении, которое сложно отменить:
выбор технологии, протокола, формата данных. Зачем: через полгода будет понятно не только **что**
выбрали, но и **почему**, и какие варианты отбросили.

## Как добавить

1. Скопировать шаблон ниже в `NNNN-kratkoe-nazvanie.md` (следующий номер).
2. Заполнить, открыть PR вместе с кодом, к которому относится решение.
3. Решения не удаляются. Если передумали — новый ADR со статусом «Заменяет NNNN», а старому ставим
   статус «Заменено NNNN».

## Шаблон

```markdown
# NNNN. Название решения

- Статус: Предложено | Принято | Заменено NNNN
- Дата: ГГГГ-ММ-ДД

## Контекст
Какая проблема и какие ограничения.

## Решение
Что выбрали.

## Альтернативы
Что рассматривали и почему отказались.

## Последствия
Что станет проще, что сложнее, какие риски.
```
