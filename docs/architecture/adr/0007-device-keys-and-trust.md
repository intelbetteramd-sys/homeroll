# 0007. Двухслойные ключи устройств и модель доверия

- Статус: Принято
- Дата: 2026-09-24

## Контекст

Устройства узнают друг друга по ключам, без аккаунтов ([ADR 0003](0003-device-pairing-by-qr.md)).
Для удалённого доступа рассматривается библиотека iroh, которая использует ключи Ed25519.
Самое надёжное хранилище на iPhone — Secure Enclave — поддерживает только P-256.
Нужно, чтобы кража или утечка ключа не давала доступа к архиву, а доступ можно было гибко ограничивать и отзывать.

## Решение

- **Ключ устройства** (ECDSA P-256) хранится в защищённом железе: Secure Enclave / Android Keystore
  (TEE, StrongBox). Он неизвлекаем и подписывает одноразовый запрос ПК при **каждом** подключении.
- **Транспортный ключ** (Ed25519, для iroh) хранится в Keychain / Keystore-обёртке, «только это устройство».
  Без подписи ключом устройства он не даёт доступа.
- **ПК — центр доверия:** хранит список устройств, их **права** (отправка, просмотр, скачивание,
  удалённый доступ, управление) и **отозванные ключи**.
- Приглашение новых устройств — QR на ПК или с телефона с правом управления.
- Журнал подключений и уведомления о новых устройствах и подключениях из новой сети.
- Экспорт ключей не предусмотрен: новое устройство — новое сопряжение.

## Альтернативы

| Вариант | Почему нет |
|---|---|
| Один ключ Ed25519 в Keychain | извлекаем на скомпрометированном устройстве, нет аппаратной защиты |
| Один ключ P-256 для всего | несовместим с iroh; пришлось бы отказаться от готового транспорта |
| Аккаунт с паролем | пароли подсматривают, подбирают и выманивают фишингом; нужен сервер ([ADR 0002](0002-local-first-no-backend.md)) |

## Последствия

- ➕ На телефонах доступ к архиву нельзя унести, скопировав файлы: нужен сам телефон.
- ➕ Гибкие права (например, «только отправлять») и мгновенный отзыв.
- ➖ На ПК ключ защищён только учётной записью ОС, пока не сделано хранение в TPM / Secure Enclave Mac.
  Вредонос на ПК остаётся вне зоны контроля приложения — это отражено в пользовательском соглашении.
- ➖ Потеря всех телефонов = повторное сопряжение (фото не теряются, они на ПК).
