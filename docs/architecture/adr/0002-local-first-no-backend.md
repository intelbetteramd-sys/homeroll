# 0002. Local-first: v1.0 без своего сервера

- Статус: Принято
- Дата: 2026-09-24

## Контекст

Продукт бесплатный. Главная ценность — приватность и отказ от подписок. Разработчик один, бюджета на
инфраструктуру нет. Хранение персональных данных на своих серверах влечёт юридические обязанности.

## Решение

В v1.0 **нет собственного сервера**:

- фото хранятся только на устройствах пользователя и в его облаках;
- доступ к облакам — OAuth PKCE прямо из приложения;
- телефон и ПК общаются напрямую в локальной сети;
- обновления desktop-версии — через GitHub Releases, сайт — GitHub Pages.

В v1.1 появляется relay для передачи через интернет: без хранения данных и без базы данных.

## Альтернативы

| Вариант | Почему нет |
|---|---|
| Своё облачное хранилище | противоречит идее продукта, стоит денег каждый месяц → подписка |
| BaaS (Firebase, Supabase) для аккаунтов | не нужен для v1.0, добавляет персональные данные и зависимость от доступности сервиса |
| Сразу делать relay в v1.0 | увеличивает объём работ и расходы; локальная сеть покрывает главный сценарий «пришёл домой — фото уехали на ПК» |

## Последствия

- ➕ Нулевые расходы, минимум юридических рисков, метка *Data Not Collected*.
- ➕ Продукт работает, даже если проект остановится.
- ➖ В v1.0 передача только в одной сети.
- ➖ Настройки облаков на каждом устройстве отдельно (до v1.2).
