# Безопасность и приватность

Homeroll работает с самым личным, что есть в телефоне. Поэтому безопасность — не отдельная фича,
а свойство каждой части продукта.

## Принципы

1. **Фотографии не покидают устройства пользователя**, кроме случаев, когда он сам отправляет их на
   свой ПК или удаляет из своего облака.
2. **Минимум прав.** Запрашиваем ровно те разрешения и OAuth-области, которые нужны сейчас.
3. **Никакой аналитики и рекламных SDK.**
4. **Удаление — самая опасная операция**, и она защищена сильнее всего.

## Модель угроз

| Угроза | Чем опасна | Защита |
|---|---|---|
| **Случайное удаление** последней копии | потеря воспоминаний навсегда | правило безопасности (≥ 1 проверенная копия в надёжном месте), предпросмотр, подтверждение, удаление только в корзину, журнал |
| Чужое устройство в той же Wi-Fi-сети | получить или подменить фото | сопряжение только по секрету из QR и с подтверждением на ПК; сессии по ключам устройств |
| Подмена ПК в сети (MITM) | телефон отправит фото злоумышленнику | пиннинг отпечатка TLS-сертификата ПК из QR |
| Кража телефона | доступ к облакам через сохранённые токены | токены в Keychain / Keystore; блокировка ОС; в приложении — «забыть устройство» с ПК |
| Утечка токена облака | чтение облака | минимальные OAuth-области, токены не пишем в логи, отзыв при отключении источника |
| Вредоносный QR-код | подключение к чужому «ПК» | QR с другого устройства требует явного подтверждения и показывает имя ПК; секрет живёт 5 минут |
| Подмена обновления desktop-версии | вредоносный код | подписанные сборки (Developer ID + нотаризация на macOS, подпись Microsoft Store на Windows), проверка подписи |
| Атака на цепочку поставок | вредоносная зависимость | Gradle dependency verification, Dependabot, минимум зависимостей, CodeQL |

## Хранение секретов

| Секрет | iOS / macOS | Android | Windows / Linux |
|---|---|---|---|
| Приватный ключ устройства | Keychain (на iPhone — Secure Enclave) | Android Keystore (аппаратный, где есть) | системный keyring (Windows Credential Manager / Secret Service) |
| OAuth-токены облаков | Keychain | зашифровано ключом из Keystore | системный keyring |
| Пароли WebDAV | Keychain | зашифровано ключом из Keystore | системный keyring |

В базе SQLite секретов нет. В журналах — нет токенов, нет содержимого фото; пути к файлам пишутся только
в локальный журнал, который пользователь экспортирует сам.

## OAuth-области (минимум)

| Сервис | Область | Зачем |
|---|---|---|
| Яндекс Диск | чтение и запись Диска (запись — только для удаления в корзину) | индексация, превью, удаление в корзину |
| Dropbox | `files.metadata.read`, `files.content.read`, `files.content.write` | запись — только для удаления в корзину |
| OneDrive | `Files.ReadWrite`, `offline_access` | то же |
| Google Фото | Picker (`photospicker.mediaitems.readonly`) | только выбранные пользователем фото |

Если пользователь не включает уборку для источника, можно запросить область **только на чтение**
(где сервис это позволяет) — делаем так по умолчанию, где возможно.

## Приватность для сторов

| Где | Что заявляем |
|---|---|
| App Store — App Privacy | **Data Not Collected** (разработчик не собирает никаких данных) |
| Google Play — Data safety | данные не собираются и не передаются третьим лицам |
| Microsoft Store | аналогично |

Если в будущем появится что-то, что собирает данные (например, relay видит IP-адреса), метки обновляем
**до** релиза этой функции.

## Политика конфиденциальности

Нужна для App Store, Google Play и верификации Google OAuth. Публикуется на сайте (GitHub Pages),
RU и EN. Структура:

1. Кто мы и как связаться.
2. Какие данные обрабатываются **на устройстве** (галерея, метаданные облаков) и что они не отправляются нам.
3. Облачные сервисы: данные идут напрямую между устройством пользователя и сервисом по его выбору.
4. Передача между устройствами — только внутри локальной сети, в зашифрованном виде.
5. Что хранится локально и как всё удалить.
6. Дети, изменения политики, дата вступления в силу.

## Процессы

- Уязвимости принимаем через [приватные отчёты GitHub](../../SECURITY.md).
- В CI: CodeQL, secret scanning, Dependabot.
- Перед каждым релизом — чек-лист: разрешения, OAuth-области, метки приватности, новые зависимости.
