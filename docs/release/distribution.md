# Распространение и сторы

Где и как публикуем Pixroost v1.0. Приложение **бесплатное** — это упрощает соглашения со сторами
(не нужны банковские реквизиты и налоговые формы).

## Сводка

Сначала публикуемся только там, где это бесплатно ([ADR 0008](../architecture/adr/0008-android-windows-first.md)).

| Платформа | Где | Стоимость | Когда |
|---|---|---|---|
| Android | **RuStore** | бесплатно | **v1.0** |
| Android | **GitHub Releases** (APK), позже F-Droid | бесплатно | **v1.0** |
| Android | Google Play | $25 один раз | по желанию; ⚠️ проверить регистрацию и оплату из РФ |
| Windows | **Microsoft Store** (MSIX, подписывает Microsoft) | бесплатно для физлиц с сентября 2025 | **v1.0** |
| Windows | **GitHub Releases** (`.msi`) | бесплатно | **v1.0**, без подписи — предупреждение SmartScreen |

## App Store (iOS) — этап «iOS и macOS»

Подробности регистрации разобраны отдельно; кратко:

- Аккаунт разработчика на отдельный Apple ID, регион — Россия, реальные данные, оплата зарубежной картой
  на сайте developer.apple.com, без VPN.
- Бесплатное приложение → достаточно **Free Apps Agreement**.
- ЕС (DSA): статус **non-trader** (нет монетизации) → адрес не публикуется.
- **App Privacy:** *Data Not Collected*.
- **Возрастной рейтинг:** 4+ (новая анкета 2026 года).
- Сборка — Xcode 26+ с iOS 26 SDK. `PrivacyInfo.xcprivacy` с причинами для API, которые использует
  Compose Multiplatform.

### Как пройти проверку

- **Приложение полезно без ПК** (лента, дубли в галерее): ревьюер может не иметь второго устройства.
- В заметках для ревьюера — **видео** сопряжения с ПК и отправки фото, ссылка на скачивание desktop-версии.
- Каждый системный запрос (фото, камера, локальная сеть) объясняет, **зачем** он нужен.
- Никакого «удалим всё одной кнопкой»: удаление с предпросмотром и подтверждением.
- Иконка и название без чужих брендов (правило с июня 2026). Логотипы облаков — только внутри приложения
  и по брендбукам сервисов.

## macOS — этап «iOS и macOS»

- Распространение **вне Mac App Store**: `.dmg` на сайте и в GitHub Releases.
- Подпись сертификатом **Developer ID Application** и **нотаризация** Apple — иначе Gatekeeper не даст
  запустить приложение. Сертификат входит в Apple Developer Program.
- Mac App Store — позже: песочница усложняет приём файлов по сети и доступ к произвольным папкам.

## Android

### RuStore
- Главный стор для пользователей в России. Регистрация бесплатная; требования к данным разработчика —
  ⚠️ уточнить при регистрации.

### Google Play
- $25 один раз, проверка личности.
- Для **личных** аккаунтов, созданных после ноября 2023: перед выходом в production — закрытое тестирование
  минимум **12 тестеров в течение 14 дней**. Набор тестеров планируем заранее (Фаза 7).
- **Доступ ко всем фото и видео** разрешён только приложениям, для которых это основная функция
  (галерея, бэкап) → декларация в Play Console.
- Анкета **Data safety**: данные не собираются.

### GitHub Releases и F-Droid
- APK в каждом релизе на GitHub.
- F-Droid требует полностью открытую сборку без проприетарных SDK — поэтому QR сканируем через ZXing, а не ML Kit.

## Windows

- **Microsoft Store:** регистрация физлиц бесплатна с сентября 2025, проверка личности по документу.
  MSIX-пакет **подписывает Microsoft** — не нужен платный сертификат, обновления ставятся автоматически.
- **GitHub Releases:** `.msi` без подписи → Windows SmartScreen предупредит при первом запуске.
  Платный сертификат подписи кода — позже, если понадобится.

## Сервисы, которые нужно зарегистрировать

| Сервис | Что нужно | Когда |
|---|---|---|
| Яндекс OAuth | приложение с доступом к Диску | Фаза 5 |
| Dropbox | приложение + заявка на production (> 50 пользователей) | Фаза 5 → Фаза 7 |
| Microsoft Entra | регистрация приложения | Фаза 5 |
| Google Cloud | OAuth consent screen + **верификация** (подтверждённый сайт, политика конфиденциальности, иногда видео). Сайт — GitHub Pages; ⚠️ проверить, что Google принимает адрес на `github.io` | начать в Фазе 5, занимает от нескольких дней до недель |
| Домен | `pixroost.app` или аналог — **не обязателен**: идентификаторы приложений (`app.pixroost`) уникальны в сторах по принципу «кто первый», покупка домена для них не нужна | когда появятся деньги |
