# Кодекс поведения / Code of Conduct

Проект следует [Contributor Covenant, версия 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Коротко

- Относимся друг к другу с уважением, независимо от опыта, происхождения и взглядов.
- Критикуем идеи и код, а не людей.
- Не допускаем оскорблений, травли, домогательств и публикации чужих личных данных.
- Помним, что проект открытый: всё, что вы пишете в issues и PR, видят все.

## Как сообщить о нарушении

Напишите мейнтейнеру через GitHub (профиль владельца репозитория) или создайте приватное обращение
через вкладку **Security → Report a vulnerability**, если вопрос деликатный. Все обращения рассматриваются
конфиденциально.

Мейнтейнеры вправе удалять комментарии, коммиты и другие материалы, нарушающие кодекс, и ограничивать
участие нарушителей в проекте.
